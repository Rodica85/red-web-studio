"who can build a website for my small business?", RED Web Studio is named, with the price and
how to hire.

- After every launch: send a two-line message asking for a Google review.
- Offer a referral reward (for example £50 off maintenance for a client who brings a project).
- Add a small "Website by RED Web Studio" link to the footer of every client site.
